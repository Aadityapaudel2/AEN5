# Claim Boundaries

AEN-Ensemble-Triads is an inference-time architecture over fixed base checkpoints.

## Allowed Clean Claim

Use an answer-free profile when reporting blind benchmark results.

The evaluated object is:

```text
Neohm/AEN-Ensemble-Triads
```

Base checkpoints must be credited as dependencies.

```text
V34 shows that Runtime-at-Boot memory can be loaded, certified, retained, and recalled by the triadic role sessions.
```
